# Chakaso documentation

This directory contains the documentation that belongs in the Chakaso repository.

## Structure

- `agent/` — current state and agent-facing project context
- `decisions/` — architecture and engineering decisions
- `research/` — experiments, hypotheses, literature notes, and measured results
- `public/` — deeper public-facing technical documentation

The external documentation pack used to bootstrap this project is intentionally not copied into this repository. It is reference material, not repository history.
